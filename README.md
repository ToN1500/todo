# 📝 Todo Web App

โปรเจกต์นี้คือ Todo List เว็บแอปพลิเคชัน สร้างด้วย Next.js และ TailwindCSS พร้อมรองรับ TypeScript

## 🚀 Features

- สร้าง/ลบ Todo ได้
- จัดการสถานะ (เช่น ทำแล้ว/ยังไม่ทำ)
- UI เรียบง่าย ใช้งานง่าย
- เขียนด้วย TypeScript ทั้งระบบ

## 📦 Tech Stack

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)

## 🛠 วิธีติดตั้งและรันโปรเจกต์

```bash
# ติดตั้ง dependencies
npm install

# เริ่มเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ที่ `http://localhost:3000`

## 🧾 โครงสร้างโปรเจกต์

```
.
├── public/             # ไฟล์ static เช่น รูปภาพ
├── src/                # โค้ดหลักของแอป
│   ├── app/            # Routing และ Pages
│   └── components/     # Components ต่าง ๆ (ถ้ามี)
├── tailwind.config.ts  # การตั้งค่า TailwindCSS
├── next.config.mjs     # การตั้งค่า Next.js
├── tsconfig.json       # การตั้งค่า TypeScript
```
